## 문제

논문별 인용 횟수를 담은 배열 `citations`가 주어질 때 H-Index를 반환한다. 논문 n편 중 h번 이상 인용된 논문이 h편 이상이고 나머지 논문이 h번 이하로 인용되었다면, 그 h의 최댓값이 H-Index이다.

- 논문 수는 1편 이상 1,000편 이하
- 논문별 인용 횟수는 0회 이상 10,000회 이하

| citations         | return |
| ----------------- | ------ |
| `[3, 0, 6, 1, 5]` | `3`    |

## 접근

> 이 문제는 혼자 힘으로 풀지 못했다. 풀이를 참고해 이해한 뒤 다시 정리한 글이라, 나중에 참고 없이 다시 풀어 볼 문제로 남겨 둔다.

인용 횟수를 내림차순으로 정렬하면, 앞에서부터 `i + 1`편의 논문이 모두 `sorted[i]`번 이상 인용된 상태가 된다. 따라서 `sorted[i] >= i + 1`이 성립하면 "i + 1번 이상 인용된 논문이 i + 1편 이상"이라는 조건을 만족한다.

1. 원본을 바꾸지 않도록 복사한 뒤 내림차순 정렬한다.
2. `h = 0`부터 시작해 `sorted[h] >= h + 1`이면 `h`를 1 늘린다.
3. 조건이 깨지거나 배열 끝에 닿으면 멈추고 `h`를 반환한다.

예시 `[3, 0, 6, 1, 5]`를 정렬하면 `[6, 5, 3, 1, 0]`이다.

| 인덱스 | 인용 횟수 | 비교  | 결과  |
| ------ | --------- | ----- | ----- |
| 0      | 6         | 6 ≥ 1 | h = 1 |
| 1      | 5         | 5 ≥ 2 | h = 2 |
| 2      | 3         | 3 ≥ 3 | h = 3 |
| 3      | 1         | 1 ≥ 4 | 멈춤  |

시간복잡도는 정렬에 따라 O(N log N)이다.

## 코드

```js
function solution(citations) {
  const sorted = [...citations].sort((a, b) => b - a);
  let h = 0;

  while (h < sorted.length && sorted[h] >= h + 1) {
    h++;
  }

  return h;
}
```

## 다시 볼 점

- 내림차순으로 정렬해서 생각할 생각을 하지 못한 것이 막힌 지점이었다. 큰 값부터 세우면 "앞에서부터 몇 편이 몇 번 이상 인용되었는가"를 인덱스로 바로 셀 수 있다.
- "h번 이상인 것이 h개 이상"처럼 기준값과 개수를 함께 묻는 문제는 먼저 내림차순 정렬을 떠올려 본다.
- 다음에는 풀이를 보지 않고 이 변환을 직접 떠올릴 수 있는지 확인한다.

> h는 배열에 있는 인용 횟수 중 하나가 아닐 수도 있다. `[10, 10, 10]`의 H-Index는 10이 아니라 논문 수인 3이다. 그래서 `h < sorted.length` 조건이 필요하다.
