## 문제

0 또는 양의 정수가 담긴 배열 `numbers`의 순서를 재배치해 이어 붙였을 때 만들 수 있는 가장 큰 수를 문자열로 반환한다.

- `numbers`의 길이는 1 이상 100,000 이하
- `numbers`의 원소는 0 이상 1,000 이하
- 정답이 너무 클 수 있으므로 문자열로 반환

| numbers             | return      |
| ------------------- | ----------- |
| `[6, 10, 2]`        | `"6210"`    |
| `[3, 30, 34, 5, 9]` | `"9534330"` |

## 접근

모든 순열을 만들면 길이가 최대 100,000이라 불가능하다. 대신 두 수 `a`, `b` 중 무엇을 앞에 둘지는 `a + b`와 `b + a`를 이어 붙여 비교하면 정해진다. 이 기준은 전체에 일관되게 적용되므로 정렬 한 번으로 답을 얻는다.

1. 모든 원소를 문자열로 바꾼다.
2. `b + a`가 `a + b`보다 크면 `b`를 앞에 두도록 정렬한다. 예를 들어 `3`과 `30`은 `"330" > "303"`이므로 `3`이 앞에 온다.
3. 정렬된 문자열을 이어 붙인다.
4. 모든 원소가 0이면 `"000"`이 되므로 첫 글자가 `"0"`이면 `"0"`을 반환한다.

시간복잡도는 정렬에 따라 O(N log N)이다(비교 한 번의 문자열 길이는 최대 8로 상수).

## 코드

```js
function solution(numbers) {
  const answer = numbers
    .map(String)
    .sort((a, b) => (b + a).localeCompare(a + b))
    .join("");

  return answer[0] === "0" ? "0" : answer;
}
```

## 다른 풀이: 숫자 뺄셈 비교

`a + b`와 `b + a`는 길이가 같으므로 숫자로 바꿔 빼도 같은 결과가 나온다. `localeCompare`보다 가볍고 의도가 더 직접적으로 드러난다.

```js
function solution(numbers) {
  const answer = numbers
    .map(String)
    .sort((a, b) => b + a - (a + b))
    .join("");

  return answer[0] === "0" ? "0" : answer;
}
```

> `[0, 0, 0]`처럼 모든 원소가 0이면 `"000"`이 아니라 `"0"`을 반환해야 한다. 2021년에 추가된 테스트 케이스가 이 경우를 확인한다.
